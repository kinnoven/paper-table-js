# Paper Table JS
Make downloadable PNG images with Title, Description, and of course Tables! Made for printing purposes but can be nice if you need something fast without using image editors.

## Usage
Title: Large title of the page. (optional)<br>

Description: Provide context. (optional)<br>

Textarea: Write comma separated text-value pairs. e.g; "Some text, 24/-"<br>

Paper Size: Choose between A4, A3, A5, & letter from the drop down _(You can add your own by inserting values in the const "PAPER_SIZE" object and then inside the <select\/> html element)_

Use double hyphen ("--") for a line separator ;)
